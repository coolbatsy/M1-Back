# M1-Back

Extracted study materials, notes, question banks, and reference documents for **Mathematics-I (M1)** backlog preparation.

---

## 📌 Repository Structure

Organized by module and topic for quick navigation during exam prep:

* **`/Notes`** – Topic-wise summaries, handwritten notes, and formula reference sheets.
* **`/PYQs`** – Previous year question papers and solution keys.
* **`/Question-Banks`** – Important problem sets and practice questions.
* **`/Extracted-Docs`** – Extracted PDF chapters and reference materials.
